## How to test

```bash
npm install
npm run build -w packages/shared
npm run prisma:generate -w apps/backend
npm test
npm run build:web
```

`npm test` fails on a fresh clone without the two middle steps (backend suites can't find
`@travel-planner/shared` or the Prisma client). That is not caused by this change.

Expected: 8 backend suites / 89 tests and 6 shared suites / 36 tests pass; web build succeeds.

  either, and both upper-case. No behaviour change expected; the spec pins it.
